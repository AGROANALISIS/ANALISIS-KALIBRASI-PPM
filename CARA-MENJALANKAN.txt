CARA MENJALANKAN DI VISUAL STUDIO CODE
1. Ekstrak ZIP, lalu di VS Code pilih File > Open Folder > folder RGB-Color-Lab.
2. Pasang ekstensi "Live Server" (Ritwick Dey) bila belum ada.
3. Klik kanan index.html > Open with Live Server.
   (Kamera dan mode "Antar Tab" hanya jalan lewat localhost/https, jadi Live Server disarankan.)
4. Butuh internet untuk font (Press Start 2P, VT323), animasi (GSAP, Lenis) dan mode Online (PeerJS).

ISI FOLDER:
index.html          web kalibrasi RGB + beranda
assets/             hero-bg.png (latar banner), hero.png (banner lengkap), badge13.png, ic-image.png
seed-wars/          catur 3D (Tunas vs Hama)
monopoli/           Monopoli Nusantara (lokal + online)
tarik-tambang/      Tarik Tambang Kuis

BERANDA:
- Latar memakai assets/hero-bg.png. Tulisan "KELOMPOK 13" dibuat hidup dari huruf piksel (SVG,
  tidak butuh font): huruf bergelombang bergantian, angka 13 berdenyut, garis menyempit.
- Petani piksel melompat-lompat di atas huruf sambil membawa tongkat sihir: aura ungu, lingkaran sihir
  tiap mendarat, serpihan bintang, dan ledakan sihir tiap berbalik arah.
- Ada kilau cahaya, bintang berkelip, gelembung di tabung reaksi, daun jatuh, kunang-kunang.
- Mati otomatis bila perangkat memakai mode "kurangi gerakan".

EFEK SUARA:
- Web utama: setiap klik ikon menu, ikon game, tombol, slider dan banner berbunyi.
  Tombol "EFEK KLIK" (kanan bawah) menyalakan/mematikan.
- Tiap game punya efek suara bertema dan musik latar, dengan tombol 🔊 (efek) dan 🎵 (musik) di bilah atas.
  Semua suara dibuat langsung oleh browser (tanpa file audio). Pilihan tersimpan di browser.

CATUR (seed-wars):
- Bot tidak lagi mengulang gerakan: bot menghindari posisi yang sudah pernah terjadi, tidak menarik
  bidak bolak-balik, dan lebih rajin mengembangkan bidak.
- Bot berpikir 1-2 detik (tergantung level) dan bidak meluncur lebih pelan.
- Aturan remis ditambah: posisi berulang 3x, 50 langkah, bidak tidak cukup.
- Suara: kayu saat melangkah, tangkap, skak, rokade, promosi, menang/kalah; musik petik + kicau burung.

MONOPOLI (monopoli):
- Mode: 1 Perangkat (2-4 pemain, manusia/bot), Online: Buat Ruang, Online: Gabung.
- Online: pilih "Buat Ruang", atur slot "Teman (online)" / Bot, bagikan kode 4 huruf atau tautan
  (tersalin otomatis), teman membuka tautan atau memilih "Gabung". Host harus tetap membuka halaman.
  Jaringan "Internet (PeerJS)" butuh internet. "Antar Tab (uji coba)" untuk mencoba di satu perangkat
  (buka game di dua tab). Pemain yang terputus digantikan Bot.
- Suara: dadu, langkah, beli, sewa, pajak, penjara, kartu, bangun rumah, bangkrut, menang; musik gamelan.
- Perbaikan: sewa stasiun/utilitas sebelumnya bisa menghasilkan NaN (uang rusak), sekarang sudah benar.

TARIK TAMBANG (tarik-tambang):
- Suara: peluit mulai, ding benar, buzzer salah, gong waktu habis, derit tali, detik terakhir,
  fanfare menang/kalah; musik tabuhan.
- Mode lama tetap: Solo vs Bot, 2 Tim 1 Layar, Online (PeerJS), Antar Tab.

FITUR KALIBRASI (tidak berubah):
Simpan/Buka data kalibrasi (foto standar, ppm, pengaturan), filter foto gaya CamScanner,
unduh CSV, kamera langsung. Filter mengubah nilai RGB, jadi pakai pengaturan yang sama untuk semua foto.
